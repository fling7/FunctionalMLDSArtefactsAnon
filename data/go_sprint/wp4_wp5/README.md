# WP4/WP5 actual data release (2026-10-19)

This is an analysis/writing data package of retained observations, not a full experiment rerunner and not a claim that every mission task passed. Native model input trees, full LLM response envelopes and caches are NOT included. Selected parsed model decisions, retained outcome rows, independent labels and coverage tables are included. Re-extracting the package requires the original pinned workspace inputs; the included verifier checks packaged bytes/counts only. No new model call or scientific evaluator run was performed to build it. UTF-8 JSONL has one object per line. JSON `null` means undefined/missing, never zero. Source references and hashes permit tracing each row without shipping model trees, caches, credentials or provider envelopes.

## Included observations

- `routing_primary_525.jsonl`: 504 real-model routing rows plus 21 no-model native B2 rows. There are 20 evaluation source rooms and one separately labelled authored example. Evaluation B0 and B1 each have 240 rows: B0 has five deviations from the independent model label, B1 zero. These labels describe agreement with the declared model, not visitor intent. The example is not pooled into evaluation.
- `http_fixed600.jsonl`: all 600 registered HTTP slots across 20 sources and two models. There are 390 generation attempts, 379 valid real generations and 593 native commits. Original statuses are 372 SUCCESS, seven E_HANDOFF_PROPOSAL, 11 HTTP_ERROR and 210 TOKEN_COUNT_ERROR. A native HTTP200/commit may use a deterministic fallback after a failed model call; it is not evidence of successful model generation. Keep `committed`, `valid_real_generation`, `real_generation_completed` and call status separate. Slot13 may use its registered conditional retry branch; the existing 600-slot cohort was not rerun or filled with replacements. The underlying transport exception for the 210 count failures was not retained, so its exact cause is unknown.
- `evolution_pairs_103.jsonl`: the exact retained 103-row report, copied byte-for-byte. Of 96 drift pairs, 45 have comparable native endpoints. Three source edits and one scripted zone rename add four comparable pairs. Three ownership-authoring-repair pairs lack both native endpoints. Total: 49 comparable, 54 explicitly undefined. No missing pair is interpreted as unchanged. `evolution_denominators.json` preserves the per-family denominators.
- `natural_four_endpoints.jsonl` and `natural_four_probes_183.jsonl`: four completed endpoint analyses of ONE source (add/remove/move/scripted-zone-rename), not four independent source rooms. They contain 61 repeated endpoint-object observations and 183 agent/object probes: 16/48,15/45,15/45,15/45. All four Gate0 checks passed, with zero independent-label disagreements and no measured object-fault counts. Those negative observations concern retained native targets, not omitted source objects or a population rate.
- `completion57_coverage.jsonl`: all 57 fixed identities. Nineteen attempts completed (eight success, 11 failure), one was interrupted at the time boundary and 37 were not executed. This is administrative closure, NOT scientific completion. `completion19_run_outcomes.jsonl` retains the completed run statuses and failure stages. Missing outcomes were not replaced or inferred; development counterparts remain labelled outside evaluation.
- `drift/`: the finalized six-file descriptive report with 10,000 source-cluster bootstrap resamples. Metric-specific pair/source denominators are explicit. Raw declared action IDs are case-namespace-sensitive; the supplementary mechanically adjusted operation/path comparison is not semantic equivalence. Python3.11/3.12 differ by tiny floating aggregation effects; cross-minor byte identity is not claimed. An optional separately supplied drift replay bundle has its own explicitly shipped inputs and limits; this table package alone does not rerun the experiment.

## Limits, cost and provenance

The expanded corpus is exploratory and outcome-informed at its disclosed preregistration boundaries. Rows are nested within rooms/source identities; do not treat every row as an independent room. Failure and undefined categories must remain in coverage tables. The unexecuted completion identities, final300-project inventory, adjunct natural analyses and real semantic judges remain incomplete. No Unity/deployment evidence is asserted.

Final accounted spend is USD7.860333200 of the USD20 hard cap; this includes USD0.661234400 for the partial completion phase. The final closure has zero pending claims and unsettled reservations. Costs are not model-quality scores.

`COUNTS.json` is recomputed from the included observations and checked against closed source receipts. `SOURCE_MANIFEST.json` pins every exact source file read by this exporter. `MANIFEST.json` hashes every delivered data/document/script file except itself. The extraction builder is retained in the original workspace, outside this analysis-only delivery; its SHA256 remains in the source manifest. `verify_release.py` checks the packaged bytes and core row/count invariants without any repository, network, credentials or ledger.
