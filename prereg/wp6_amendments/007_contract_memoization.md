## Proposed scope

experiments/static_contract_memoization_v3.py wraps only backend.roomcontract_v2_runtime._load_project_contract_unchecked inside a process-local context nested within the already approved static_model_memoization scope. It also memoizes structural._simple for string inputs. All original callables are restored in finally. No request, routing decision, provider/action choice, runtime fingerprint, digest comparison or session mutation is memoized. Every checker and every normal/stale pair/variant still executes the frozen evaluator. No publication or concurrency claim can use these runs.

Only the audited native V2 branch is eligible: explicit matching native version fields, supported generation mode, project metadata keys from the frozen allowlist, and all resolved dependencies inside the materialized project. Legacy, unknown-generation, unrecognized metadata keys, external references and unsupported file kinds fall back to the original loader. Native model and trace contents are keyed in full, including unknown fields; no field projection can hide a mutation. Original invalid outcomes are never cached.

On every call, parse current project.json and resolve/read these dependencies afresh: project.json, optional agents.json, version-detection active trace path (declared trace_map_path or trace_map.json), version-detection native path (declared model_path or roomcontract.v2.instance.json), actual native path (model_path or v2_path or default), actual trace path (declared trace_map_path or trace_map.v2.json). Missing optional paths are explicit values, and resolved paths plus all exact bytes form the SHA256 cache key. Added/deleted/changed files or path declarations therefore miss. Required-file errors, unsupported branches and snapshot exceptions use the original loader. Native metadata and trace validators remain part of the original miss path. A successful first load is cached only if a second fresh dependency snapshot is identical.

Before each hit returns, call the original runtime._sha256 on the actual native file with the current declared scheme and require equality to the stored successfully validated model hash. Thus fresh reads and actual digest computations are retained. The outer load_project_contract publication_protocol handling is untouched; cooperative loader checks still run on every call. Exact input equality, not modification timestamps, authorizes reuse. The assumption is immutable model files during WP6 admission experiments; this is not a concurrent publication implementation.

Cached contracts are serialized to trusted in-memory pickle buffers created only by this process from the original successful return value. Every hit reconstructs an isolated deep copy; no pickle file or untrusted serialized input is read. LRU capacity is four contracts and 64 MiB of serialized outputs per worker, separate from the existing trace cache. Read failures, loader exceptions, or changed-during-load observations are not cached. Every memo counter is saved separately and excluded from semantic outcomes.
