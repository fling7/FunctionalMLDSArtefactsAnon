# WP6 reporting correction: room-cluster bootstrap resamples

Status: approved reporting-only protocol-compliance correction, finalized 2026-10-15 after independent root review. This is not an execution amendment, retrospective preregistration or significance-based analysis choice.

The mission brief section 6.7 requires pooled room rates to use a room-cluster bootstrap with at least 10,000 resamples and a fixed seed. The derived source-accounting helper previously defaulted to 2,000. The exact correction changes only `source_cluster_interval(..., repetitions=2000)` to `repetitions=10000`; seed 20261015, whole-source sampling, quantile method, applicability rules, source joins, estimates, and the original mutant-level Wilson intervals stay unchanged. Small explicit resample arguments remain available for unit fixtures; production pooled checker reporting uses the corrected default.

`experiments/wp6_provenance.py` is absent from active 007-010 execution locks and available original execution inventories. The evaluator/worker/launcher and actual contract/compilation helpers do not import it. The pin audit is retained in `drafts/wp6_reporting_10000/pin_audit_v2.json`, and all active 010/008/009 execution and registry pins passed again after this change. No active evaluator, independent implementation, native model, source selection, classifier or worker configuration changed.

The original helper and tests are retained byte-for-byte under `drafts/wp6_reporting_10000/original/`. Existing reports remain untouched. The comparison uses the exact same saved partial snapshot: 130 mutants, 20,368 pairs and two source rooms. Its native/raw outcome pins and the supplied source-manifest/geometry pins are reverified. Corrected outputs are in `results/processed/wp6_combined_progress_001_bootstrap10000_v1`; the original is `results/processed/wp6_combined_progress_001`.

All nine focused tests pass. They verify actual 10,000-resample execution (20,000 cluster draws for a two-source fixture), fixed seed, deterministic repeat output, input preservation, pooled-checker use, missing/unresolved provenance and applicability denominators. The complete output comparison found 188 resample/defined-replicate counter changes from 2,000 to 10,000. Interval endpoints did not change for this particular two-source partial snapshot. All other normalized report values, every CSV byte, all confusion/label/denominator counts, and all saved raw inputs remain identical. Destination path changes are separately normalized; no other change is permitted by the comparison script.

This correction does not improve the representativeness of the partial corpus. The source bootstrap remains an exploratory supplement with very few clusters, and undefined intervals remain undefined. No new evaluation or provider call was made. Future derived reports should use the corrected default; historical 2,000-resample outputs remain discoverable as superseded evidence, not silently rewritten.

Exact old/new source, tests, output, comparison and input pins are in `drafts/wp6_reporting_10000/review.json`; `output_delta.json` records the complete field/file comparison. The existing report-generator source is unchanged; the review manifest binds its helper dependency explicitly.
