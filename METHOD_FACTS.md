# Method facts

F0 is the retained contract model_sha256 (LF-normalized serialized native model digest). F1 is contract_runtime_fingerprint over the packet contract using the backend's exact implementation. F2 hashes the Gate0 routing table plus sorted declared runtime actions. F3 adds selected agent prompt fields (id, display_name, name, persona, expertise, knowledge_tags, system_prompt, description) and SHA256 hashes of knowledge documents. These are whole-model experimental scopes, not a per-query minimal slice. F0–F3 are recomputed on the49 independently comparable evolution pairs; fingerprint changes do not prove semantic changes. Gate0 is used in scope construction; independent routing labels come from the separately retained I1/I2 comparison.

Real-model snapshots: gpt-4.1-mini-2025-04-14 and gpt-4.1-2025-04-14. Reject study: temperature0.3, abstention allowed, one repetition, fixed seed20261019, three prompt conditions, conservative cost-prefix scaling frozen before calls. Source scenes and faults are deterministic; generation calls are real. The new study has no natural multi-hop/unreachable pair if none exists in the retained corpus; seeded faults are labeled as seeded.

Coding assistance: Codex/GPT-6 family, exact hosting snapshot not exposed. Do not invent a more specific version. Historical independent implementers were procedurally isolated, not OS-isolated. Sprint work is dated2026-10-19. Fresh W6 and W7 reviewers are separately spawned contexts with restricted instructions; their actual findings and verification scope are in review/.

A001 (2026-10-15): clarified digest, selected identity, specificity, native path and trace checks and separated publication from admission. A002: explicit applicationActionKind overrides endpoint inference; declared-schema and offline-reference rules clarified. A003: selected trace fields, duplicate wire IDs, complete answering paths and schema dialect handling clarified. All precede differential evaluation; these are specification-author clarifications, not independent validation of the specification.

Native auditing reuses retained authoring reports and I1/I2/Gate0 outcomes only after checking the native model digest. New audits execute the pure reference and compiled unchanged ASP policy and retain disagreements. Authoring success, publication success, pipeline completion and semantic correctness are distinct. Native pre-repair models are unavailable when repair happened before assembly; exact retained stage candidates remain separate.

CPU cost cells use process_time_ns, scripted zero-latency responses, classroom plus programmatically built300/1000 scene-object fixtures with three agents. Each complete cell has200 calls and discards its first10, with randomized interleaving. Component boundaries are in the retained cost/design.json: baseline is SessionStore chat with gates1–3 replaced by verified descriptors, commit cells include fresh load and fingerprint, evidence append is separate, and admission helper includes snapshot comparison. Concurrent sprint load and filesystem work limit latency interpretation. The baseline is not an end-to-end HTTP baseline.

Mutation ground truth is the retained narrow routing-fault endpoint; reachability-only policy rejection need not be a routing fault. TP/FP/FN/TN count mutants, stratified by checker/operator/fault class. Undefined ground truth and nonapplicable validators are explicit exclusions. Backend setup refusal is not an executed routing rejection. Missing or interrupted workers remain missing observations. Source-related mutations and within-room pairs are correlated; Wilson bounds are descriptive mutant-level intervals, not population confidence claims.

Protocol guarantees require cooperating publishers/readers and lock/journal assumptions. Unlocked file readers, direct edits, external side effects and durable session recovery are outside the guarantee. Default backend behavior is unchanged, including retained specification disagreements.
