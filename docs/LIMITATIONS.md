# Limitations and scope

The core guarantee concerns target identity, declared ownership, one-hop reachability, action binding and commit consistency. It does not establish visitor intent, factual answer correctness, prompt safety, sensible responsibility assignments, or appropriate model updates. An ownership swap can be structurally valid and semantically inappropriate.

Independent implementations provide procedural L2 implementation diversity under a shared specification and orchestrator. They do not establish specification validity or independence of research authors. The default backend still differs from the clarified SPEC on six input categories; these discrepancies are disclosed rather than erased by changing a reference.

The current natural corpus comes from deterministic synthetic source descriptions processed by real models. It is not a deployed-user sample or independent field corpus. Pipeline errors, infrastructure failures, repairs and repetitions are distinct outcomes. A valid-generation subset can be selected by feasibility, creating selection bias. Room-level clustering is necessary; exhaustive dependent requests are not independent observations.

The cooperative publication claim depends on shared locks and a complete generation manifest. Direct external writes and unlocked readers can violate that visibility discipline. Journal recovery does not recover process-local sessions, and rollback does not compensate external side effects or provide exactly-once delivery. Windows behavior has been tested; Linux portability still requires clean-environment evidence.

The property generator explores small native models, not every model size or schema dialect. Scripted clients are appropriate for transaction and fault tests but cannot measure natural model proposal rates or answer quality. Complete scale measurements, human authoring effort, Unity use, framework benchmarks and natural evolution labeling remain absent.

Research-track eligibility is conditional on the explicit go/no-go checklist. A positive result in one work package must not conceal an unmet minimum elsewhere.
